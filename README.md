# 📚 Book Store SQL Analysis Project

## 🚀 Project Overview
This project is based on a Book Store Database where SQL is used to analyze sales, customers, revenue, and inventory data.  
The main goal of this project is to solve real-world business problems using SQL queries and database concepts.

The project focuses on:
- Sales Analysis
- Customer Insights
- Revenue Tracking
- Inventory Management
- Genre & Author Analysis

---

# 🛠️ Tech Stack
- SQL
- PostgreSQL
- DBMS Concepts

---

# 🗂️ Database Structure

### 📖 Books Table
Contains information related to books such as:
- Title
- Author
- Genre
- Price
- Stock

### 👤 Customers Table
Contains customer-related details such as:
- Name
- Email
- City
- Country

### 🛒 Orders Table
Contains order transaction details such as:
- Ordered Books
- Quantity
- Total Amount
- Order Date
